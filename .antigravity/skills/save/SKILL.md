# /save Execution Instructions

当用户输入 `/save` 时，严格执行以下步骤：
1. 梳理当前会话全部上下文及修改的代码。
2. 更新根目录下的 `docs/HANDOFF.md`，严格遵循以下 3 部分填充：
   - **## 1. 需求说明**：综合归纳用户在对话中提出的所有需求、输入输出格式与约束规则。
   - **## 2. 当前进度与已踩的坑**：
     - 列出当前已完成并验证的代码/功能点。
     - 记录明确被否决的技术尝试或避坑经验（严禁新会话重复踩坑）。
   - **## 3. 关键代码资产**：列出承载本次成果的核心代码文件和对应测试用例路径。
3. 提示用户完成本地保存/Git Commit，并在新窗口直接输入 `/resume`。
